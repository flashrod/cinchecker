How to read one

Twenty-one characters, six parts

Reliance Industries Limited's CIN.

L Listing
17110 Industry
MH State / ROC
1973 Year
PLC Type
019786 Registration

The two-letter code is a registrar jurisdiction: PN (Pune) and MH both mean Maharashtra.

LLPIN

Shorter, and quieter

An LLPIN is AAA-1234: three letters, a hyphen, four digits. It carries no state, year, or company type.
